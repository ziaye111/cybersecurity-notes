# Software Security Assignments

This folder contains the assignments I completed while studying Software Security.

I decided to keep these exercises here as part of my cybersecurity learning repository because they show some of the practical topics I worked with during the course.

The assignments include work with C, C++, Java, Python, assembly/control-flow representations, binary analysis, program transformations, and other software-security related exercises.

## Assignments

- Assignment 01 – introductory C and low-level programming exercises
- Assignment 02 – program analysis and control-flow related exercises
- Assignment 03 – control-flow and binary analysis exercises
- Assignment 04 – executable/binary-based exercises
- Assignment 05 – program analysis exercises
- Assignment 06 – Java-based program analysis exercises
- Assignment 07 – binary analysis and debugging exercises
- Assignment 08 – C, Python and program-analysis exercises
- Assignment 09 – C and analysis exercises
- Assignment 10 – branch transformations and opaque-branch related work

Some assignments contain JSON, Graphviz (`.gv`) files, screenshots, or executables because these were part of the format used for the exercises.

These files represent coursework and my learning process rather than polished production software.
