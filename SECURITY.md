# Security policy

## ScopeGuard itself

Please report vulnerabilities in ScopeGuard privately through GitHub's **Report a vulnerability** flow when it is enabled for this repository. Include a reproduction, affected version, impact, and a suggested fix when possible. Do not include secrets or private target data.

## Using ScopeGuard

ScopeGuard is intended only for systems you own or have explicit written permission to assess. It performs read-only checks, but even a normal HTTP request can be sensitive in some environments. Confirm scope, rate limits, and maintenance windows with the system owner before running it.
