# Contributing

Thanks for helping make ScopeGuard clearer and safer.

## Before opening a pull request

- Keep the tool read-only and limited to authorised assessment workflows.
- Explain the user-facing security decision behind a new check.
- Add or update focused tests.
- Use plain language in findings: what happened, why it matters, and what to do next.
- Do not include real target data, credentials, tokens, or private reports.

Run `python -m unittest discover -v` before submitting a pull request.
